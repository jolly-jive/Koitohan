# Device configuration examples

Configuration examples that make network devices use Koitohan for RADIUS login, syslog and TFTP. Contributors send them from their own devices (see [CONTRIBUTING.md](../../CONTRIBUTING.md)). The examples are written in English only.

The maintainer has not checked these examples on real devices. Each example says who checked it, on which firmware and when, whether on hardware or on a virtual image, and what was checked. Behavior can change with other models and firmware versions, and can differ between hardware and a virtual image.

For the `nas_type` values and the reply attributes they select, see [RADIUS clients](../configuration.md#radius-clients).
